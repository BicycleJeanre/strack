# STrack

An offline-first Sudoku progressive web app in the same family as FTrack and GTrack. STrack is intended to be hosted on GitHub Pages, installable on phones and desktops, and fully usable without a network connection after installation.

The initial implementation brief is in [docs/PRODUCT_BRIEF.md](docs/PRODUCT_BRIEF.md).

## Planned product principles

- Local-first play with bundled, pre-rated puzzles and durable in-progress games.
- A clean responsive interface that follows the established FTrack/GTrack visual conventions while remaining purpose-built for a Sudoku grid.
- Separate corner and centre pencil marks, cell colours, logical hints, undo/redo, keyboard and touch support, and light/dark/system themes.
- Explicit Sudoku Explainer (SE) ratings rather than an unexplained Easy/Medium/Hard label.
- Static GitHub Pages deployment with no runtime dependency on a third-party puzzle API.
